Conhecimentos

HTML

HTML é a base de toda página web. Ele define a estrutura do site e a organização do conteúdo. Usa tags semânticas para melhorar acessibilidade e SEO.

CSS

CSS é responsável pelo visual da página. Controla cores, fontes, espaçamentos e layouts. Permite criar designs modernos e responsivos. Usa Flexbox e Grid para alinhamento preciso.

JavaScript

JavaScript traz vida para o site. Permite criar interações e comportamentos dinâmicos. Manipula elementos HTML e estilos via DOM. É usado para validações, animações e lógica.
